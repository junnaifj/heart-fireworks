# Heart Fireworks

An interactive, single-file HTML5 Canvas fireworks display. Every explosion forms a heart while retaining the original launch trails, gravity, glow, and particle fade.

一个基于 HTML5 Canvas 的交互式爱心烟花网页。每次爆炸都会形成爱心，同时保留原版的发射轨迹、重力、光晕和粒子渐隐效果。

## Live demo / 在线演示

### [Open Heart Fireworks / 点击打开爱心烟花](https://junnaifj.github.io/heart-fireworks/)

## Features / 功能

- Click or tap anywhere to launch a heart-shaped firework.
- **Auto Show** launches a sequence of fireworks.
- **Finale** launches multiple waves at once.
- Responsive full-screen canvas with stars and moonlight.
- No frameworks, dependencies, build tools, or external assets.

- 点击或触摸任意位置发射爱心烟花。
- **Auto Show** 自动连续发射烟花。
- **Finale** 同时发射多轮烟花。
- 自适应全屏画布、星空和月光背景。
- 无框架、无依赖、无需构建工具或外部资源。
