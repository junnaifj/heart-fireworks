# Usage Guide / 使用说明

## Online

[Open the live Heart Fireworks webpage](https://junnaifj.github.io/heart-fireworks/)

## Controls / 操作

- **Click or tap the sky:** launch one firework toward that position.
- **Auto Show:** launch eight fireworks across the sky.
- **Finale:** launch several rapid waves of fireworks.

- **点击或触摸天空：** 向指定位置发射一枚烟花。
- **Auto Show：** 在天空中连续发射八枚烟花。
- **Finale：** 快速发射多轮烟花。

## Local use / 本地使用

Download the repository and open `index.html` in Chrome, Edge, Firefox, or Safari. The page is self-contained and works without a server or internet connection.

下载仓库后，用 Chrome、Edge、Firefox 或 Safari 打开 `index.html`。网页为单文件应用，无需服务器或互联网连接。
